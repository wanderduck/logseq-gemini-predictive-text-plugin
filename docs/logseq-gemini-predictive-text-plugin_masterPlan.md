# Master Plan: Logseq Gemini Predictive Text Plugin

## Phase 1: Project Scaffolding & Setup
1. **Initialize Project:** Scaffold a new Logseq plugin project using Vite, React, and `@logseq/libs`.
2. **Manifest Configuration:** Set up the `package.json` and `manifest.json` for Logseq integration.
3. **Settings UI Construction:** Build the plugin settings schema using `logseq.useSettingsSchema` to include:
   - Authentication Mode (OAuth vs. API Key).
   - API Key input field.
   - Trigger Mode (Automatic pause vs. Manual trigger).
   - Manual Trigger Hotkey choice (CTRL+Space vs. ALT+Space).
   - Model selection.

## Phase 2: Authentication & Gemini API Integration
4. **Authentication Layer:** Implement the Google/Gemini OAuth flow to utilize subscription-based inference, alongside a fallback implementation utilizing the official `@google/generative-ai` SDK for API key users.
5. **Gemini Service Module:** Create the service that constructs prompts, manages API interactions, and requests multiple suggestion variants per completion.

## Phase 3: Context Aggregation & RAG System
6. **Local Context Gathering:** Build utilities to extract the current active block, cursor position, and surrounding blocks from the current page (`logseq.Editor.getPageBlocksTree`).
7. **Global Database RAG:** Implement the semantic/keyword querying logic across the entire Logseq graph (`logseq.DB.q`) as a fallback when the model needs broader context to generate confident suggestions.
8. **Feedback Loop & Few-Shot Memory:** Develop a background storage mechanism (e.g., writing to a hidden Logseq config page) that saves a custom dictionary of user words and logs accepted/rejected completions to use as few-shot prompt examples for stylistic matching.

## Phase 4: UI Integration & Event Handling
9. **Event Interception & Trigger Logic:** Attach DOM listeners to the Logseq editor to handle the chosen Trigger Mode (either a debounced `input` listener for pauses, or a `keydown` listener for the manual hotkey).
10. **Tooltip Prediction UI:** Create a floating React UI component (`logseq.provideUI`) anchored directly below the cursor's pixel coordinates. This tooltip will render the multiple predictions generated by Gemini.
11. **Keyboard Navigation & Insertion:** Implement `keydown` interception to navigate the multiple suggestions in the tooltip (e.g., using Up/Down arrows), dismiss them (`Escape`), and insert the chosen prediction directly into the Logseq editor (`Tab` or `Enter`).
